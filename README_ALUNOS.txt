UNIFECAF SHOP - ATIVIDADE DE INVESTIGAÇÃO EM QA

Como executar:
1. Descompacte a pasta recebida.
2. Abra o arquivo index.html no navegador.
3. Preferencialmente, use a extensão Live Server no VSCode para executar o projeto.
4. O site utiliza uma API pública externa, então é necessário estar conectado à internet.

Arquivos principais:
- index.html: estrutura da página.
- style.css: estilos visuais.
- script.js: regras de interação, carrinho, formulário e consumo de API.

Objetivo:
Investigar o sistema como um profissional de QA, testando comportamento, layout, mensagens, regras de negócio, validações e integração com API.
